# SymmetricOrthogonalPolynomials.jl
A Julia package for orthogonal polynomials that capture symmetry. 

This package implements the (strong) Laplacian  of Invariant and Anti-invariant polynomials under permutations of the symmetric group $S_3$, as used in [LaplacianS3.jl](https://github.com/Jpunter16/SymmetricOrthogonalPolynomials.jl/blob/main/examples/LaplacianS3.jl).

It also implements the closed form of the (strong) Laplacian for Invariant polynomials under $S_n$, for arbitrary dimension, with an example in [PoissonInvariant.jl](https://github.com/Jpunter16/SymmetricOrthogonalPolynomials.jl/blob/main/examples/Poisson%20Invariant.jl).
